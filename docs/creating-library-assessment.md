# Creating a Library assessment

Once you choose a library assessment, you then need to give it a name (e.g. Python Developer) and select which choice of language/framework the candidate has to write their solution to the assessment in.

You can then set the deadline & time limit for the assessment. You can also select whether a <a href="https://code-screen.github.io/Candidate-Video-Docs" target="_blank">video recording</a> is required from the candidate to explain their
solution and if you want to <a href="https://code-screen.github.io/docs/#/anonymizing-candidates" target="_blank">anonymize candidate</a> details.

<figure>
  <figcaption style="font-style: italic;"></figcaption>
  </br>

</figure>

<br>

* `Deadline` - The maximum number of days the candidate has to start the assessment once it is sent to them.

* `Time limit` - The maximum number of hours/days the candidate has to complete the assessment once they start the assessment.

You will also notice that we display a recommended maximum `Time limit`. Please **note** that all our library assessments are designed
to be successfully solved within 60-90 minutes. We do, however, suggest a time greater than this to avoid making candidates 
feel unnecessarily stressed, which allows them to perform better on the assessment.

All of our library assessments contain a suite of unit tests. A candidate's solution must pass all of these unit tests for us to mark them as having
passed the assessment.

Once you have filled out all the above, then click the `Publish` button, and you can start [sending](sending-assessments.md) your new assessment to candidates!
