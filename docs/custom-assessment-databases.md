# Custom Assessment Databases

 A common pattern for backend, full-stack & data science/ML take-home coding tests is that the candidate is required to write code in a language, such as Python, to query a `SQL`/`NoSQL` database and perform some actions on the returned data.

 For each candidate, the company has to to spin up a database, create tables, prepopulate the tables with data, set security groups (to allow candidates to access the DB from their local machine), etc., which becomes a very time consuming & tedious process.

 By using CodeScreen's Database feature, we can automate this process for you!
