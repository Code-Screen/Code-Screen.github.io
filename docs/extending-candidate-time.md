# Extending Time

If you would like to extend the time a candidate has to complete their test, you can click the blue + icon to the right
of the time left value for that candidate.

<figure>
  <figcaption style="font-style: italic;"></figcaption>
  </br>
  <img style="max-width: 80%;" src="inProgress.png" alt="In Progress Candidate"/>
</figure>

<br>

You will then see the following pop-up:

<figure>
  <figcaption style="font-style: italic;"></figcaption>
  </br>
  <img style="max-width: 40%;" src="extendTime.png" alt="Extend Time"/>
</figure>

<br>

If the candidate has not started the test, the number of hours/days you choose here will be added to the 
`existing deadline` the candidate has to start the test from when they were sent the test. The `existing deadline`
here refers to the `Deadline` value you had set for this test when you sent the test to this candidate.

If the candidate has started the test, the number of hours/days you choose here will be added to the
`existing time limit` the candidate has to submit their solution from when they started the test. The `existing time limit`
here refers to the `Time limit` value you had set for this test when you sent the test to this candidate.

Once you choose the number of hours/days, click the blue `Confirm` button, and that's it!
